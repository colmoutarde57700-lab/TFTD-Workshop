# TFTD Workshop 2.12.7 — Benjamin et GPT-6 édition
First public release of the evolving TFTD/Workshop project, for Windows x64.

Download the Windows ZIP, extract it, and run the EXE. Configure your own TFTD/OXCE resources in Resources.
Full offline documentation and interface: French, English, Spanish and German.

REAL HD texture or debug now works alongside remastered PNGs or universal PNG templates. Choose the terrain mode under Render, then the PNG provider under PNG alongside REAL HD.
GEO_TERRAIN uses SAND materials in the same preview. Map and gameplay data are unchanged.

The portable archive includes the executable and documentation. The source archive includes the code, translation catalogues, guides, build script and tests. No game data or external texture packs are bundled.

Known limits: Workshop preview omits full game shaders/effects; GEO editing/picking, plan display and MAP/OXCE export remain unavailable. GEO scenes save in JMW4. Project is still in development.
108 regression + 40 rendering + 75 procedural + 64 language/tutorial checks and 4 preference reloads passed locally. In-game/user acceptance of this version remains pending.
