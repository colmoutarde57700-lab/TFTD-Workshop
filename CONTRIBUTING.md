# Contributing
Report version, render mode, dataset/MCD/frame, scene/seed and expected/actual result. Screenshots should show assemblies when seams are involved.
Preserve accepted geometry and alpha. A complete rock assembly must not become scattered fragments.
Translate locales/fr.json, en.json, es.json, de.json while preserving identifiers, paths and printf parameters. Edit docs/chapters.json in all four languages.
Run python tools/regenerate.py and the relevant build/tests. Explain what was verified in Workshop, in OXCE and by the user separately.
No commercial game files should be committed.
